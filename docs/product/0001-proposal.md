# 0001 — 立项书

> 项目最终定名：**K9999**，副标题 Master Orchestrator（主控编排器，多 Agent 总指挥）
>
> 落盘日期：2026-10-20　状态：proposal

## 1. 项目基本信息

- **项目名称**：K9999（Master Orchestrator）多 Agent Web 工程 CLI
- **技术栈**：Bun + TypeScript + TUI + MCP + 本地沙箱
- **开发模式**：从零自研 Harness，**不基于 Pi 内核**。`k9999-agent-harness` 作为 v1 原型验证仓库，不再迭代内核
- **开发周期**：总 12 周。MVP（调度器 + 架构 + 后端 Agent）4 周，正式版 8 周，商业化配套 12 周
- **核心壁垒（区别于 Pi / CrewAI）**：
  1. 内核原生 DAG 任务依赖调度，支持并行子 Agent
  2. 原生 PTC 批量工具脚本，减少 LLM 轮次
  3. Web 工程垂直领域内置范式，开箱即用，无需反复配置 Prompt

## 2. 立项目标

1. **技术目标**：完成自研多 Agent 调度内核，实现角色化分工、任务拆分、结果合并、冲突校验。打包为单二进制文件，无运行时依赖
2. **产品目标**：覆盖 Web 应用全生命周期：需求拆解 → 架构设计 → 前后端开发 → 单元测试 → Docker / CI 部署
3. **商业目标**：个人付费用户加小团队订阅。首年 1500+ 个人用户，付费转化率 ≥ 8%，30+ 小团队订阅客户

## 3. 里程碑排期

| 阶段 | 时间 | 交付物 |
|---|---|---|
| 阶段 1 MVP | 第 1–4 周 | 基础 Harness + 调度器 + 架构 Agent + 后端 Agent，完成 PTC 批量调用 |
| 阶段 2 产品成型 | 第 5–8 周 | 新增前端 + 测试 + DevOps Worker，DAG 并行调度，会话树 + 项目级长期记忆 |
| 阶段 3 商业化版本 | 第 9–12 周 | 权限审计、容器沙箱、打包分发、授权系统，配套付费扩展包 |

## 4. 立项结论

赛道避开通用编码 Agent 红海，锁定 Web 小团队工程场景。多 Agent 调度加 PTC 属于内核级创新，竞品复制成本高。CLI 本地二进制分发，交付成本极低，商业化路径清晰。**同意立项。**

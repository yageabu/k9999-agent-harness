# 0003 — PRD 产品需求文档

> 状态：proposal

## 1. 产品概述

### 1.1 产品名称

K9999（Master Orchestrator）

### 1.2 产品定位

本地 CLI 多 Agent 协作工具，专注 Web 应用全链路工程。面向独立开发者与 3–10 人小微团队，把需求自动拆解为架构、前后端、测试、DevOps 任务，多 Agent 并行协同，一键完成项目从 0 到部署。

> Master Orchestrator（主控编排器）：整个系统大脑，如同乐团总指挥，负责拆解需求、编排与调度多个专家 Agent 协同完成 Web 工程项目。

### 1.3 用户痛点

1. 单人开发全栈项目，架构、编码、测试、部署来回切换，效率低下
2. 通用 AI Agent 只能单步修改代码，大项目重构时 LLM 轮次过多，等待时间长
3. Agent 之间自由对话容易跑题，无法严格按照工程流程执行
4. 缺少 Web 领域专属工程规范，生成代码不符合项目目录与技术栈规范

### 1.4 核心价值

1. 角色分工：多 Agent 各司其职，自动拆分任务，并行执行无依赖工作
2. PTC 批量执行：一轮思考执行多步工具调用，减少一半 LLM 交互轮次
3. 垂直领域：内置 Vue / React + Java / SpringBoot + Docker 全套 Web 工程模板
4. 本地安全：纯本地运行，文件与命令沙箱隔离，不上传项目代码到云端

## 2. 核心功能架构

### 2.1 顶层核心模块

**1）调度主控器（Master Orchestrator）**：整个系统大脑。接收需求 → 解析项目现状 → 生成 DAG 任务依赖图 → 分配子任务 → 合并结果 → 冲突校验 → 闭环验收。

**2）5 个领域 Worker 子 Agent（角色固化，不可自由闲聊）**

- 架构 Agent：需求拆解、技术选型、项目目录设计、数据库表结构、风险评审
- 后端 Agent：API 接口、业务逻辑、数据库 CRUD、异常处理
- 前端 Agent：Vue / React 组件、页面、TS 类型、状态管理、样式
- 测试 Agent：单元测试、接口测试、代码缺陷检查
- DevOps Agent：Dockerfile、docker-compose、CI 脚本、服务器部署、日志排查

**3）Harness 运行内核**

- 会话树：分支 fork、历史回溯，继承 v1 已验证的交互
- PTC 批量工具脚本执行引擎（核心差异化）
- 项目级长期记忆：跨会话保存项目架构、表结构
- 文件与 Shell 命令多级沙箱加人工审批弹窗
- MCP 协议统一工具入口

**4）权限与审计模块（团队版独有）**：操作日志、命令白名单、文件读写权限、会话导出审计报告

### 2.2 功能清单（分版本）

#### 免费开源版

- 基础单 Agent 模式
- 文件读写、Shell 命令、Git 基础工具
- 会话树、人工审批
- 仅开启后端与前端两个 Worker
- 只能串行执行，无任务并行，无 PTC 批量调用

#### 个人付费版（永久授权）

- Master 主控调度器加全部 5 个角色 Agent
- DAG 任务依赖调度，无依赖任务自动并行执行
- 内核 PTC 批量工具脚本，大幅减少 LLM 轮次
- 项目级长期记忆，跨会话共享项目知识库
- 完整 Web 工程模板（SpringBoot + Vue3、React + Node）
- 容器沙箱，一次性 Docker 执行命令，不污染本机环境
- 本地会话导出、多分支会话管理

#### 团队订阅版（额外增加）

- 多人团队权限管控
- 全操作审计日志，可导出合规报告
- 团队共享工程模板库
- 统一模型密钥管理，成员共用 API 配额

## 3. 核心业务流程（标准 Demo 流程）

1. 用户输入自然语言需求：开发一套电商后端加管理前端，包含商品、订单、用户模块
2. Master 调度 Agent 扫描当前空目录，生成 DAG 任务：
   - 任务 1（前置）：架构 Agent 做技术选型加数据库设计，串行先行
   - 任务 2、3（并行）：后端 Agent 写接口，前端 Agent 开发页面
   - 任务 4（后置）：测试 Agent 自动编写单元测试
   - 任务 5（收尾）：DevOps Agent 生成 Docker 部署脚本
3. 各个 Worker 独立执行，只领取自己的任务，不互相闲聊
4. Master 调度器汇总全部代码，自动合并文件，检查代码冲突
5. 全部完成后，一键执行 Docker 打包部署

## 4. 非功能需求

1. **性能**：Bun 二进制启动 ≤ 200ms。PTC 批量执行相比单步 Function Call，LLM 轮次减少 ≥ 45%
2. **兼容性**：Windows / macOS / Linux 三平台单二进制
3. **安全**：命令黑名单加交互式人工审批。容器模式下命令运行在临时容器，执行完毕自动销毁
4. **可扩展性**：支持自定义 MCP 服务、自定义工程模板

## 5. 验收标准（MVP 阶段）

- 输入完整 Web 项目需求，系统可以自动拆分任务，并行生成前后端代码
- PTC 脚本可以一次性执行文件创建加代码写入加 Shell 命令，不需要多轮思考
- 会话树可以创建分支、回滚历史会话
- 所有命令执行都弹出人工审批弹窗，防止误操作
